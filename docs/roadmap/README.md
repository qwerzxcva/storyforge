> 权威范围：仅长篇小说；节点模式是同一产品的操作表达。世界设定、显式派生、导入导出和历史作品恢复是支持能力，不单独作为产品。

## 状态

- `NEXT`：当前最近施工单元。
- `IN_PROGRESS`：已开工且仍有明确验收缺口。
- `QUEUED`：长篇前置完成后进入。
- `BLOCKED`：缺少外部条件或真实验收证据。
- `DONE`：本条声明范围已有当前代码与自动验证。

## 支持底座

世界设定属于长篇 Work。显式派生出的 World 保留来源和 revision，不回写源 Work；世界编辑入口不作为独立产品导航。旧 WorkKind 只为既有作品的读取、迁移、备份与恢复保留，新建仅接受长篇小说。

共享数据、三注册表、Harness、产品目录和客户端构建只保留满足长篇主链或历史数据安全所需的能力。其他产品的专项方案与完成记录不构成当前 backlog，不恢复相应入口。

## 开工规则

1. 每项工作必须指向长篇用户路径、数据生命周期或可靠性缺口。
2. 复用当前长篇 Skill、Context Gateway、Adoption、Project Tables 和恢复机制，不建平行系统。
3. 对历史数据只读、迁移、备份与恢复的改动要有正反例；不因下线创建入口删除用户作品。
4. 验收绑定具体目标提交；CI 红灯按已核实根因修复，不改阈值、不跳过失败。
